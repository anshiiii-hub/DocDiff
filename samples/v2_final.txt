DocDiff — Project Overview

This project aims to automate manual document review by comparing two or more versions of a report, assignment, or policy file and producing a structured difference report.

The system identifies additions, deletions, and modifications at the block level. For edited blocks, it further highlights word-level changes so reviewers can see exactly what changed.

Supported input formats include plain text (.txt), Markdown (.md), Word (.docx), and PDF (.pdf).

With DocDiff, the review process is reduced to seconds, ensuring 100% accuracy across consecutive version pairs.

Final approval is pending management board review before public release.
